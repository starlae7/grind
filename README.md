# Telegram Bot "Discipline & Success"

Этот бот создан для поддержания дисциплины и отслеживания успеха с использованием ИИ наставника в стиле Andrew Tate.

## Требования
- Python 3.11+

## Запуск локально
Для работы вебхуков локально потребуется проброс портов (например, через ngrok). Без этого бот не будет получать сообщения. Для локальной разработки без ngrok лучше переписать код обратно на long polling (как было раньше).

## Деплой на Bothost.ru (с поддержкой Webhook и Mini App)
1. Инициализируйте Git в папке с проектом и сделайте пуш на GitHub (в приватный или публичный репозиторий).
2. Зайдите в панель управления Bothost.ru и создайте приложение (выберите Python).
3. В настройках хостинга:
   - Включите галочку **Использовать домен** (Bothost выдаст вам домен, например `https://bot1234.bothost.tech`).
   - В поле **Главный файл** укажите `bot.py`.
4. В разделе "Переменные окружения" (или `.env` файл на хостинге) укажите:
   - `BOT_TOKEN`
   - `GEMINI_API_KEY`
   - `WEBHOOK_HOST` — укажите домен, который вам выдал Bothost (ОБЯЗАТЕЛЬНО с `https://`, без слеша на конце, например: `https://bot1234.bothost.tech`).
5. Нажмите "Запустить".

Бот сам установит вебхук, и Mini App будет автоматически работать по адресу:
`ваши-домен/webapp/index.html`.
5. Убедитесь, что команда запуска на хостинге указана как `python bot.py`.
6. Нажмите "Запустить/Перезапустить" бота в панели Bothost.
