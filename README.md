# Telegram Bot "Discipline & Success"

Этот бот создан для поддержания дисциплины и отслеживания успеха с использованием ИИ наставника в стиле Andrew Tate.

## Требования
- Python 3.11+

## Запуск локально
1. Переименуйте `.env.example` в `.env` и вставьте свои ключи:
   - `BOT_TOKEN` — токен от @BotFather.
   - `GEMINI_API_KEY` — бесплатный ключ от Google AI Studio (начнется с `AIza...`).
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите бота:
   ```bash
   python bot.py
   ```

## Mini App (Планировщик)
Бот теперь поддерживает **Mini App**. HTML файл лежит в папке `webapp/index.html`.
Чтобы он работал в Telegram:
1. Залейте весь этот код в GitHub репозиторий.
2. В настройках репозитория включите **GitHub Pages** (Settings -> Pages -> Branch: main -> /root).
3. GitHub выдаст вам ссылку (например, `https://username.github.io/reponame/`).
4. Откройте файл `keyboards/reply.py` и в строке `web_app=WebAppInfo(url="...")` замените URL на вашу ссылку (добавив `/webapp/index.html`).
5. Перезапустите бота.

## Деплой на Bothost.ru
Так как Bothost поддерживает деплой через клонирование репозитория, выполните следующие шаги:
1. Инициализируйте Git в папке с проектом и сделайте пуш на GitHub (можно в публичный, чтобы работали GitHub Pages, либо залейте `webapp` в отдельный публичный репо).
2. Зайдите в панель управления Bothost.ru и создайте приложение (выберите Python).
3. Укажите ссылку на ваш репозиторий для клонирования.
4. В разделе "Переменные окружения" (или `.env` файл на хостинге) укажите `BOT_TOKEN` и `GEMINI_API_KEY`.
5. Убедитесь, что команда запуска на хостинге указана как `python bot.py`.
6. Нажмите "Запустить/Перезапустить" бота в панели Bothost.
